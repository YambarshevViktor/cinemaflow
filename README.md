# CinemaFlow — v0.7.1

Плавающая панель на странице фильма. Без встраивания в верстку сайтов, без хрупких якорей.

> Название сменилось с AllFilm на **CinemaFlow**. Все слова про «баннер» убраны из кода, ID и текстов — блокировщики рекламы больше не прячут панель. Старые настройки подхватываются автоматически (миграция `allfilm_*` → `cinemaflow_*`, дальше каталог обновляется сам через слияние v2).

## Что умеет
- Появляется сама в правом нижнем углу на карточках фильмов: `imdb.com/title/*`, любой поддомен `kinorium.com` / `kinorium.net` (`www`, `ua`, `ru`, …), `themoviedb.org/movie/*`, `letterboxd.com/film/*`. Детект — по JSON-LD/og:type, плюс шаблоны URL. Новый сайт добавляется двумя строками в манифест (matches + web_accessible_resources) — несложно, панель уже умеет читать любую карточку с JSON-LD.
- Язык интерфейса: **RU/EN** переключатель в настройках (названия сервисов не переводятся). Панель подхватывает язык живьем.
- Зеркала: у сервисов может быть несколько доменов. Проверка пингует все, открывается первое живое; в настройках под ссылкой — сразу чипы зеркал с удалением и кнопка «+ зеркало» (никаких подписей «⇄ зеркала» — только ссылки). В панели каждое зеркало — отдельный пункт списка (`Название · host`), выбирается руками. Мертвые домены пропускаются автоматически. Автообновления «откуда-то» нет и быть не может — рабочие домены быстро дохнут (LordFilm!); поэтому: проверка показывает, какие живы, свежие добавляются вручную, у измененных записей видна дата (`изм. 07.11`). Ввод строго проверяется: мусор вместо адреса отклоняется.
- Запрос строится под сайт: где год мешает (TMDB, Filmix) — ищется только название (`qmode: title` в каталоге).
- Стекло Tahoe: светлая/темная тема — от системы **и** от сайта (на темном сайте панель темная: смотрим `data-theme`/класс/яркость фона, живьем следим за сменой).
- 3 группы, на каждой главной кнопке — 1 ссылка (первая включенная, не текущая, предпочтительно живая):
  - **Онлайн-кинотеатры:** HDRezka, Rezka, LordFilm, Filmix (+ выкл. по дефолту: KinoGo, Seasonvar, KinoKrad)
  - **Базы:** Kinorium, IMDb, Letterboxd (+ выкл.: Rotten Tomatoes, Metacritic, TMDB, JustWatch)
  - **Торренты (твои 5):** RuTracker, Rutor, TheRarBg, Ext.to, BT4G
- Слева у каждой ссылки favicon, справа точка живости (зеленая/красная/серая).
- Умный пропуск текущего сайта — всегда, без настроек: на Kinorium кнопка покажет IMDb, на IMDb — Kinorium. Текущий в списке серый «вы здесь».
- Мертвые по health-check не ставятся на главную, лежат в списке серыми.
- Раскрывающийся список открывается **вверх поверх панели**, со своим скроллом и никогда не обрезается карточкой. Клик по пункту порядок больше не меняет — только `↑↓` в настройках.
- `⧉ Копировать название` — копирует `Название Год`. Та же кнопка есть в настройках (панель запоминает последний фильм). `Проверить зеркала` — пингует favicon через background (с таймаутом и локальным фолбэком — зависнуть в «Проверяю…» нельзя). `⚙️` — открывает настройки (такая же есть в самих настройках — открывает полную страницу).
- Крестик закрывает до следующего фильма.
- Настройки: галочки вкл/выкл, порядок `↑↓` (= порядок в кнопке, цифра показывает место среди включенных), удаление **любой** записи (встроенные после удаления каталог не возвращает, только «Сброс»), кнопка **✎ Изменить** у любой записи (имя + URL + режим запроса; правки встроенных каталог не перезаписывает, помечаются датой), свои ссылки (название необязательно — подставится из хоста; `%s` необязателен — обычная ссылка откроется как есть) и свои зеркала к любому сервису.
- Иконки: берутся напрямую с сайта (`/favicon.ico`), без гугл-сервиса — его «глобус»-заглушка больше не перекрывает букву. Нет иконки — всегда аккуратная буква в цветном кружке.
- Где показывать: панель появляется на карточках фильмов IMDb, Kinorium, TMDB и Letterboxd. ✕ закрывает до следующего фильма. Управление — только галочками в секции **Сайты** настроек: Kinorium (.com/.net) — одной группой-пилюлями, остальные — своими строками. Кнопки 🚫 в панели больше нет.
- Кнопки ведут на **страницу поиска** сайта (название + год) — прямую ссылку на карточку фильма без его ID получить нельзя, поэтому дальше один клик по результату на самом сайте. Важно: панель живет только на карточках фильмов IMDb/Kinorium — добавленная ссылка это *куда* искать, а не *где* показывать панель.

## Установка (Chromium)
1. `chrome://extensions` → Developer mode → Load unpacked → выбрать эту папку.
2. Открыть фильм на IMDb или Kinorium → справа внизу появится панель.
3. Иконка расширения → настройка списков.

## Проверить перед публикацией
- Шаблоны поиска TheRarBg / Ext.to / BT4G / LordFilm / Filmix / Seasonvar / KinoKrad / Kinorium могут поменять query-параметр — открыть руками по одному разу.
- RARBG оригинальный мертв с 2023, в дефолте его форк TheRarBg.

## Структура
```
manifest.json
content/panel.js       — Shadow DOM панель, детект фильма, SPA-слежение за URL, тема от сайта
background.js          — health-check + OPEN_SETTINGS
defaults/catalog.json  — весь каталог + дефолтные галочки
popup/                 — настройки
icon/                  — иконки
```

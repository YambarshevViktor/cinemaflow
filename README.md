# CinemaFlow
Плавающая панель на карточке фильма (IMDb, Kinorium, TMDB, Letterboxd): ищет фильм везде — онлайн-кинотеатры, базы, торренты. Один клик вместо десяти вкладок.

## Что умеет
- На странице фильма — кнопки **HDRezka, Filmix, Letterboxd, RuTracker…**: клик ведёт на поиск `Название Год` на этом сайте
- **Зеркала**: проверяет, какие домены живы, открывает рабочее; каждое зеркало — отдельным пунктом, свои добавляются в пару кликов
- **RU/EN** переключатель, тема подстраивается под сайт (на тёмном — тёмная)
- Свои ссылки, правка любого шаблона (✎), удаление любых записей, выбор сайтов, где показывать панель

## Установка 
1. Скачай код: зелёная кнопка **Code → Download ZIP** и распакуй
2. Открой `chrome://extensions`, включи **Developer mode**
3. **Load unpacked** → выбери распакованную папку
4. Открой любой фильм на IMDb — панель появится справа внизу

## Настройки
Клик по иконке расширения: галочки, порядок кнопок (↑↓), зеркала, язык, сайты. Панель запоминает последний фильм — его название копируется кнопкой «⧉ Копировать название» и в панели, и в настройках.

## Разработка
```
manifest.json          — точки входа, список сайтов
content/panel.js       — панель (Shadow DOM, тема от сайта, SPA-слежение)
popup/                 — настройки
defaults/catalog.json  — каталог ссылок и зеркал
common/shared.js       — строки RU/EN, общие helpers
```
Без сборки: правишь файлы → жмёшь «обновить» на `chrome://extensions`. Свои правки каталога не перезаписывают (слияние по версии).
